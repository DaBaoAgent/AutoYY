# Laorou 老肉风格口播稿管线

把纪录片/万物科普素材（SRT/视频/主题）写成**老肉杂谈式闲聊科普口播稿**：像跟观众唠嗑一样把一件事从"由头"讲到"门道"，全程口语、短句、带钩子、带考据、带纠正，最后以艾伦签名收尾。

风格蒸馏自 `D:\BaiduSyncdisk\3 艾伦和艾薇\老肉杂谈\` 内老肉杂谈原片转写稿（大白菜/丹顶鹤/猪笼草/乌鱼子/麋鹿，2026-09-02），全文读法见 `references/laorou-style-guide.md`。

## 触发条件

- 用户说"老肉风格/克隆老肉/像老肉那样写/闲聊科普风"写某话题口播稿
- 用户说"laorou 管线"生成/批量生成爆款文案
- 已有普通爆款口播稿，想要一版"唠嗑讲门道"风格的改写

## 核心特征（六要素，写作时必须全中）

1. **由头开场**：不直接报题。先从一个具体由头进（时令/新闻/上期回顾/一件东西/一句老话），再自然引到本期主角，说"今天这期啊，咱就来好好认识一下XX"。
2. **悬念定调**：开场或转场处抛出"离谱/误会/反常识"钩子，明说"待会咱详细说/下面细说"，制造追看欲。每篇 1-3 个钩子型知识反转。
3. **口语唠嗑推进**：短句一句一行式口吻，靠"然后/再一个/另外/你像/完事/也就是说"推进；自问自答"那到底…呢？哎…"；预设观众疑问"可能有朋友已经想到了/有观众可能会有疑问"。
4. **引经据典译白话**：聊历史就引古籍（本草纲目/诗经/地方志/苏轼等）原文一两句，**立刻翻译成大白话**，不掉书袋。
5. **考据+纠正**：习惯性纠正流俗认知（"好多人以为…其实…"）；拿不准就明说（"科学家们还在争论/推测是/还没明确记录"），不说死。
6. **结尾签名铁律**：写完内容收个尾（"好了，XX的事啊就先说到这"），然后**必须逐字结尾**：

```
（我是艾伦，遛狗去了，拜了个拜）
```

整句一个括号一行，作为稿件最后一行，不得遗漏、不得改写、不得加字减字。稿件通篇以艾伦第一人称"咱/我"叙述（不出现"老肉"自称）。

## 语气词/口癖弹药库（高复用）

句尾确认：是吧 / 就这么个意思 / 是这么个过程
转折设问：哎 / 那…到底是怎么回事呢 / 为什么呢？因为…
举例展开：你像 / 你想 / 比如来说
推进连接：然后 / 再一个 / 另外 / 完事 / 也就是说 / 说白了
感叹惊讶：就很离谱 / 太夸张了 / 谁能想到 / 就这么夸张
预告钩子：待会咱详细说 / 咱接着往下说 / 回头再细说 / 下面细说
不确定：推测是 / 还不太确定 / 科学家们还在争论 / 并没有很明确的记录

（注：转写稿中这些词密集出现；口播稿不必每句都塞，保持 3-5 句一个语气词的自然密度。）

## 结构模板（4500-5500 字版）

1. **由头+报题**（150-300字）：由头一段，引出主角，报"今天这期啊，咱就来好好认识一下XX"
2. **身份定位**（300-500字）：这是什么（分类/别名/物种或机构/定义），名字怎么来的（中文名/外文名由来），有什么标签
3. **误区纠正**（300-500字）：大众最常有的误会/刻板印象，逐条纠正，往往带一个"原来如此"反转
4. **门道展开**（2000-3200字）：按 2-4 个"技能/特质/门道"分块讲透，每块先给结论再拆机制，配生活化类比；可引历史/名人/典籍佐证（引完译白话）
5. **与人的关系**（400-600字）：吃法/用法/文化影响/现实争议/现状，落到"这事跟咱有关系"
6. **收尾+签名**（100-200字）：“好了XX的事就先说到这”，一句回扣开场由头，然后固定签名句。

字数口径：非空白中文 4500-5500（`len(re.sub(r'\s+','',text))`）。素材不足写不满时明说缺口，不硬编。

## 写作纪律

- **禁儿化音（铁律，2026-09-02）**：主播艾伦是江苏口音设定，讲标准普通话，全文不得出现名词/语气类的北方儿化音。**注意：近指/远指/疑问词 "这儿/那儿/哪儿" 是自然口语，保留不替换**（2026-09-02 用户确认）；"这里头/那里头"（=这里面）为固定搭配同样保留。需替换的常见儿化→标准说法表：这会儿→这时候、那会儿→那时候、待会儿→待会/等一会儿、今儿个/明儿个/昨儿个→今天/明天/昨天、事儿→事情（出事儿→出事、没事儿→没事、找事）、活儿→活（干活儿→干活）、词儿→词、字儿→字、点儿→点（有点儿→有点、差点儿→差点）、劲儿→劲（使劲儿→使劲、一股劲）、味儿→味/味道、门儿清→门清/一清二楚、玩意儿→东西、没准儿→没准、头儿→头/老大、主儿→人/号人、大伙儿→大家、哥们儿→兄弟、爷们儿→男人、一会儿→一阵/片刻、主角儿→主角、带劲儿→带劲。改写后必须整句通读，别扭就整句重写，别机械删字。校验时注意别误删"儿子/女儿/儿童/育儿/闺女/婴儿"等合法词。
- **事实锚定素材**：每个数字/人名/日期/引语都能在源 SRT/资料里找到；找不到就不写或写模糊（"应该是/大概"）。
- **纯中文**：英文专名/人名/地名全部音译或意译成中文；不用 em dash（——）；不夹英文。
- **无 AI 腔**：不用"首先/其次/综上所述/值得注意的是/本质上/不是A而是B"这类套壳句；不排比铺陈；不空泛升华。
- **短句为骨**：一句一个意思，能断则断；但避免整篇等长短句节奏（长短交错才像人话）。
- **推测与事实分开**：素材里推测语气的话（they must have / I'm assuming）转写时用"应该是/据推测"，别写成既成事实。
- **禁止原创**：不发明情节、数字、人物内心。ASR 乱码片段只写字幕明说的部分。

## 写作流程

1. **读透素材**：SRT 先清洗（去滚动字幕重复行），覆盖开头+中间+结尾；纪录片回顾/多人群像片逐个认人认事件，抓关键数字与引语。
2. **列钩子**：从素材里挑最反常识/最离谱/最有反转感的 1-3 个点做"待会细说"钩子。
3. **起草**：按六要素+结构模板写，通篇艾伦第一人称唠嗑口吻。
4. **校验**：跑字数（4500-5500 非空白）、结尾签名句逐字在、纯中文、无 em dash、关键事实/数字仍在稿中。
5. **落盘**：写入目标目录（不覆盖已有原稿时用 `爆款口播稿-老肉版.txt` 等不冲突文件名），回报路径与字数。

## Pitfalls

- **别把"老肉"写进稿子**：这是艾伦的号，风格克隆老肉，但自称必须是"咱/我（艾伦）"，样本里"大家好我是老肉"的开场一律不照抄。
- **口语≠注水**：语气词用来调节奏，不靠重复凑字数。每段仍要有新信息。
- **引经据典必须译**：引古籍/外文名后不给白话解释 = 掉书袋，扣分。
- **钩子必须兑现**：开场说"待会细说"的点，后面必须真的展开讲，不能悬空。
- **监狱/案件等题材**：老肉式闲聊照样适用（把监狱当"生态系统"讲规矩门道），但血腥暴力画面一笔带过，重点在规则/机制/人物生态。
- **结尾签名是铁律**：任何任务 brief 与签名句冲突时，以本技能签名为准；漏签名=稿件不合格。
